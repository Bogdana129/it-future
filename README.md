# IT Future 2026 — сайт реєстрації на конференцію

Навчальний адаптивний лендінг для реєстрації на IT-конференцію. Стек: **HTML5**, **Bootstrap 5**, **CSS3**, **JavaScript** (без фреймворків для логіки).

## Функції

### Сторінка

- Герой-блок із закликом до дії
- Блок «Про подію» з картками переваг
- Опис типів квитків **Standard** (400 грн) та **VIP** (800 грн)
- Адаптивна навігація (Bootstrap)
- Темний технологічний дизайн: градієнти, «скляні» картки, анімації

### Форма реєстрації

| Поле | Перевірка |
|------|-----------|
| Повне ім'я | Мінімум 2 символи, літери / пробіл / дефіс |
| Email | Формат `name@domain.tld` |
| Кількість Standard / VIP | Цілі числа 0–99, разом ≥ 1 квиток |
| Промокод | Необов'язково |

### Калькулятор квитків (`script.js`)

1. Рахує суму: `кількість × ціна` для кожного типу.
2. **Знижка за кількістю** (усіх квитків разом):
   - 1–2 квитки — 0%
   - 3–4 квитки — **10%**
   - 5 і більше — **20%**
3. Промокод **`EVENT50`** — мінус **50 грн** після відсоткової знижки.
4. Підсумкова сума **не нижча за 0 грн**.
5. У блоці «Детальний розрахунок» показується покроковий текст.

У коді використано:

- `const` — ціни, промокод, посилання на елементи DOM
- `let` — змінні в розрахунках (сума, відсоток знижки)
- Арифметика: `+`, `-`, `*`, `/`
- Умови: `if` / `else if` / `else`

## Як запустити

1. Відкрийте файл `index.html` у браузері (подвійний клік або «Live Server» у VS Code / Cursor).
2. Заповніть форму та натисніть **«Розрахувати та відправити»** або **«Лише розрахунок»**.
3. Перевірте знижки, наприклад:
   - 2 Standard → 800 грн (без %)
   - 3 Standard → 1200 − 10% = 1080 грн
   - 5 VIP → 4000 − 20% = 3200 грн
   - 3 Standard + промо `EVENT50` → 1080 − 50 = 1030 грн

## Структура проєкту

```
it-future/
├── index.html   — розмітка та Bootstrap
├── style.css    — кольори, картки, анімації
├── script.js    — валідація та калькулятор
└── README.md    — цей файл
```

## Як використовувати Cursor AI для такого проєкту

1. **Опишіть завдання цілим промптом** (як у навчальній вправі): технології, ціни, знижки, промокод, стиль, розділення файлів.
2. **Уточнюйте по частинах**: «додай валідацію email», «зроби мобільне меню», «поясни функцію calculateTickets простішими коментарями».
3. **Перевіряйте згенерований код**: відкрийте `script.js` і простежіть логіку `if` для знижок — це гарна вправа для початківця.
4. **Просіть рефакторинг без ускладнення**: наприклад, «залиш тільки const/let, без класів ES6».
5. **Дизайн**: можна додати «зміни палітру на бірюзовий акцент» або «додай темну тему з контрастнішим текстом» — Cursor змінить лише `style.css`.

> Порада: після генерації обов’язково протестуйте граничні випадки (0 квитків, невірний email, промокод з помилкою, велика кількість квитків із 20% знижкою).
